# OpenClaw WebHub Channel

Connect OpenClaw to any Website via HTTP/WebSocket - a generic channel for custom integrations.

## What is WebHub?

WebHub is a **standalone web service** that bridges your Website with OpenClaw. It enables:
- **Two-way messaging** between your Website and OpenClaw
- **Webhook-based** message delivery
- **Token-based** authentication
- **Custom message formats** for any use case

## Quick Start

### 1. Install the Channel

```bash
# Install via npm (coming soon)
npm install -g @openclaw/webhub

# Or from source
git clone https://github.com/chatu-ai/openclaw-web-hub-channel.git
cd openclaw-web-hub-channel
npm install
npm run build
openclaw extensions install ./
```

### 2. Configure OpenClaw

```bash
# Enable the channel
openclaw config set channels.webhub.enabled true

# Set WebHub service URL (provided by your Website)
openclaw config set channels.webhub.webhookUrl "https://your-website.com/webhub"

# Set access token
openclaw config set channels.webhub.accessToken "wh_eyJhbGciOiJIUzI1NiIs..."

# Start the gateway
openclaw gateway start
```

### 3. Test Connection

```bash
openclaw channels test webhub
```

## Architecture

```
┌─────────────┐                    ┌─────────────┐
│  Your       │ ←─ HTTP/WebSocket ─→│  OpenClaw   │
│  Website    │      (双向通信)       │  Gateway   │
│             │                    │            │
└─────────────┘                    └─────────────┘
       │                                  │
       │ 1. Deploy WebHub Service          │ 2. Configure OpenClaw
       │ 2. Get Access Token              │ 3. Start Gateway
       ▼                                  ▼
   You (Website Operator)            OpenClaw User
```
